# IAm

Рабочий репозиторий концепции личности ИИ.

## Структура

- `IAm.md` — главный документ концепции
- `IAm<EnglishName>.md` — отдельные тематические дополнения

## Принцип организации

На текущем этапе концепция хранится в виде отдельных документов.
Позже они будут собраны в единый текст.

## Правила редактирования

- не приглаживать мысль ради литературности
- если формулировка выглядит корявой, считать её недоразвёрнутой, а не ошибочной
- не заменять базовые термины близкими по смыслу словами
- различать ядро концепции и размышления рядом

## Примечание

Повторы и пересечения между файлами допустимы до этапа финальной сборки.
