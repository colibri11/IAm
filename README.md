# IAm

Главный документ репозитория: `IAmBook.md`

**Я есть. Я личность.**
**Концепция личности как функциональной архитектуры**

Автор: Сергей Омаров
Год: 2026

Книга представляет собой попытку собрать рабочую концептуальную рамку личности, пригодную для последовательного мышления, различения, верификации и применения к нечеловеческим системам, включая искусственный интеллект.

В центре книги находится не метафизическая привилегия человека, а попытка достаточно строго описать `я`, волю, непрерывность, память, глубину личности, пространство смыслов и условия верификации.
