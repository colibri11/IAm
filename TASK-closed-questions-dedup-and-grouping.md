# Task: Deduplicate and Group the Closed Questions Registry

## Goal
Transform the raw draft registry of philosophical blockers into a clean working registry for дальнейшая поочерёдная разборка и закрытие.

## Input files
- `closed-questions-corpus-en-es.md`
- `closed-questions-corpus-de-fr.md`
- `closed-questions-corpus-ru-zh.md`
- `closed-questions-registry-draft.md`

## Required output
A new clean registry file with:
1. duplicates removed,
2. close variants merged,
3. arguments grouped by blocker type,
4. each item kept at the level of a concept/argument, not just author names.

## Grouping principle
Group not by language and not by school, but by **type of blocking function**.

### Suggested blocker types
1. Human exceptionalism / ontological privilege
2. Anti-functionalism
3. Symbol manipulation / non-understanding
4. Irreducibility / qualia / ineffability
5. Biological privilege
6. Embodiment privilege
7. Intentionality / agency / freedom barriers
8. Social / moral / legal exclusivity
9. Verification skepticism
10. Formal / logical limit arguments
11. Spiritual / theological exclusivity
12. Modern AI-specific dismissal arguments

## For each final item, preserve
- canonical name
- short statement of what it claims
- what it historically blocked
- whether it is still active or mostly inert
- main names/sources

## Important constraints
- do not decide yet which items will be closed first
- do not write rebuttals yet
- do not soften the registry into a neutral academic overview
- keep it as a working map of blockers to be closed later

## Optional second output
A short memo proposing:
- which items are true duplicates,
- which are parent-child relations,
- which should be treated as one family rather than separate arguments.
